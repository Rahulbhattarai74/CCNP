# CCNP Enterprise Study Repository

> A structured repository documenting my journey toward the Cisco Certified Network Professional (CCNP) Enterprise certification.

---

## About

This repository serves as my personal knowledge base for CCNP Enterprise. It includes study notes, hands-on lab exercises, Cisco IOS configurations, network automation scripts, and interview preparation material.

The goal is to build both theoretical knowledge and practical networking skills through consistent documentation and lab practice.

---

## Certification Track

### ENCOR 350-401

The core exam covering:

- Network Architecture
- Virtualization
- Infrastructure
- Network Assurance
- Security
- Automation

### ENARSI 300-410

Advanced routing and services including:

- Layer 2 Technologies
- OSPF
- EIGRP
- BGP
- MPLS
- VPN Technologies
- IPv6
- Troubleshooting
